# Prisca Dezigns Email Templates

Brand: Prisca Dezigns — Web and AI Solutions.

Brand type system:
- Display: DM Serif Display (fallback: Georgia, serif)
- Secondary: Cormorant (fallback: Georgia, serif)
- Body/UI: Urbanist (fallback: Arial, sans-serif)

Email implementation: custom web fonts are not reliable across all email clients, so the fallback fonts must remain visually acceptable. The final sending version should use a publicly hosted logo asset under priscadezigns.org or an inline image.
